# CrossApp
Наскрізний проєкт з крос-платформного програмування.
Предметна область: Каталог відеоігор. Сутності: Game.
Призначення: облік ігор, додавання відгуків та архівування.

## Інваріанти доменної моделі (Лабораторна 4)
- **ID, Назва та Жанр** не можуть бути порожніми.
- **Рік випуску** має бути в межах від 1950 до поточного.
- **Оцінка відгуку** має бути в діапазоні від 1 до 10.
- **Заборонено** додавати нові відгуки до гри, яку вже перенесено в архів.
- **Заборонено** повторно архівувати гру, якщо вона вже має статус "В архіві".

## Запуск
dotnet build

dotnet run --project src/Cli
